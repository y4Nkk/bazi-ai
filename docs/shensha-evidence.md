# 神煞文献证据库与目录

本目录是 ZP-1 当前冻结神煞查表的唯一文献索引。它把“可从公开文本直接定位的查法”“项目采用的流派变体”和“尚未完成原典定位的查表”分开记录；后两类绝不被表述为已经获得文献确认。

神煞在本项目中只产生可追溯的注记，不参与旺衰、格局、喜忌、领域结论或趋势指数。条目中的“依据”只描述触发查法，不采纳古籍中的人物、婚育、疾病、死亡、灾祸、贫富等断语。

## 证据等级

| 等级 | 含义 | 是否计入“原典已核验” |
| --- | --- | --- |
| 原典直引 | 所列公开文本的对应章节明确给出或可直接推出本项目的查表。 | 是 |
| 流派变体 | 原典存在同名/同类条目，但当前表选择了一个明确标记的流派取法。 | 否，须审校 |
| 待原典核验 | 当前查表仍在运行目录中，但尚未完成逐字、逐条定位。 | 否 |

“原典直引”仅指查法的文本可追溯，不等于该体系能够预测现实结果，也不等于获得具名命理师审校。
