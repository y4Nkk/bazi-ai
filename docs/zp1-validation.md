# ZP-1 验证与人工审校包

ZP-1 是一套可复现的传统规则引擎，不宣称传统命理具有可证明的现实预测能力。本文件记录代码之外仍必须由独立来源或审校者确认的事实。

## 当前规则版本

- 算法版本：`zp-1.3.4-<规则目录指纹>-noaa-eot-2006-lunar-typescript-1.8.6`
- 计算入口：`calculateBaziSnapshot`
- 历法事实：`lunar-typescript@1.8.6`
- 真太阳时：经度差 + NOAA 2006 均时差模型；出生时刻和每个真太阳时流时均使用 IANA 时区的实际瞬间。

## 经典规则对读

- 《三命通会》卷八列出“戊寅日壬子时、卯月”为正官格。`tests/structure.test.ts` 使用 1906-04-04 00:00 的完整历法四柱 `丙午 辛卯 戊寅 壬子` 固化该分类对读；只验证“主格为正官格”，不采纳或测试原文中的贵贱、灾祸等人生断语。[原文](https://zh.wikisource.org/zh-hant/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E5%85%AB)
- 《三命通会》卷五明确月令优先，并把刑冲破害、伤官、七杀等列为正官格的破格因素。ZP-1 将这类取舍固定为单一结构裁决与证据状态；具体流派差异仍须由下方审校者确认。[原文](https://zh.wikisource.org/wiki/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%94)

- 公开万年历的独立四柱样本：<https://huangli.100xgj.com/day/19900515>
- 2024 立春公开表存在秒级分歧：部分表列 [16:26:53](https://wwj.beijing.gov.cn/bjww/wwjzzcslm/1729028/1729037/1729027/436356026/index.html)，当前锁定模型和[另一公开表](https://www.time163.com/toolbox/ershisijieqi/2024.html)列 16:27:07。ZP-1 固定采用后者，任何使用前者的工具只能作为“分钟级/四柱级一致”对照，不能宣称秒级一致。
- 不同历法模型的秒级差异必须记录，不能通过改写测试或展示分钟来掩盖。

## 外部产品范围对照（非规则来源）

- [问真八字公开首页](https://pcbz.iwzwh.com/#/home/index)当前展示排盘、合盘、案例记录、名人案例、学习课堂和会员等模块。它说明成熟同类产品的内容/服务范围更宽，但不公开可供复现的完整规则、计算版本或逐条证据，因此不能作为 ZP-1 的历法或流派判定来源。
- ZP-1 仅将它作为范围对照：V1 保留可复现排盘、时序与 BYOK 解读；不引入账号、记录/分享、会员、社交或合盘。外站的任何人生断语、案例结论和界面字段均不进入测试夹具、规则目录或分值。
- 其公开排盘表单包含姓名、性别、公历/农历/四柱入口、地点经纬、夏令时、真太阳时、早晚子时和保存案例。ZP-1 覆盖姓名、传统性别、地点/经纬、真太阳时和晚子时规则，但以 IANA 时区 + 显式偏移的唯一 `birthInstant` 取代手动夏令时开关；手工四柱被拒绝，农历只作为输出历法事实而不作为 V1 输入路径，保存案例不进入无账号的 V1。这些差异是单一可复现合同的选择，不是未声明的兼容缺口。

## 请审校者逐项确认

1. 月令、藏干、十神、建禄/月劫/羊刃的取法是否符合本项目锁定流派。
2. 合化的月令、化神可见、冲害破刑与争用裁决是否可接受；特别确认三会内部成员不应被当作组外阻碍。
3. 化气、从强、从儿、从财、从官杀的严格阈值与回归普通格条件是否足够严谨。
4. 正官见伤官、食神见偏印、正财见劫财、正印见正财的受损规则及救应优先级是否符合目标流派。
5. 调候、扶抑、通关/救应的优先顺序，以及最终喜忌五行排序是否一致。
6. 大运顺逆、起运折算、原局 + 大运 + 触发层才允许强结论的限制是否合适。
7. 十领域的传统表述是否过度、是否包含任何疾病诊断、必然婚育、死亡或灾祸断语。
